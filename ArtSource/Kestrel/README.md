## 当前优先级（用户最新纠正）
- 先把模型结构做好，暂停动画、骨骼扩展和材质制作。
- 用户明确指出关键问题是模型本身。v01/v02 外形不符合写实基准，不能用贴图掩盖体型问题。
- `v03/Kestrel_Model_v03.blend` 是无贴图的结构重建草稿：连续截面躯干、重新定位眼喙、缩短裸露腿段、修订收翅静态轮廓。
- 仍未完成：红隼头颈比例与姿态、喙和眼眶塑形、翼根融合、覆羽叠层、腿羽与躯干连接。当前不是已验收模型。
- `v03/Previews/` 用于检查灰模；无正式动画，未替换 Unity 玩家。
- 当前构建入口为 `v03/build_clay.py`；`revise_structure.py` 是一次性迁移记录，不要再次执行覆盖后续修订。

## 已确认
- 写实最低验收基准：用户提供的 WDallgraphics / RedKite Unity 模型展示和 12 张模型、线框截图。当前结构草稿不达标；具体差距见 `References/Review_Notes.md`。
- 写实方向；褐头、背部与尾部横斑较多的外观。
- 先模型、骨骼、蒙皮；首版正式动画为起飞、飞行、悬停、降落。
- Blender 为模型源文件；动画工具可用 Cascadeur。
- 配色依据用户第二批照片，结构同时参考第一批展翅照片；不混用灰头雄鸟的羽色，不带照片中的猎物。

## 初版范围
当前制作结构初版，仍需近景羽毛、收翅叠层与变形复核，不能视为最终写实成品。
使用米制、Z 向上、朝 -Y；FBX 转为 Unity 的 Y 向上。
躯干、颈、头、翼的肩肘腕、飞羽、尾羽、腿与趾分别支持控制。
源文件放在 Assets 外，确认后再导入 Unity，避免自动替换现有玩家。
四段正式动画尚未制作；姿态检查与正式游戏动画区分。

## 当前文件与验证
- `Kestrel_Structure_v01.blend`：结构草稿，包含模型、蒙皮、骨架与评审灯光相机。
- `Export/Kestrel_Structure_v01.fbx`：骨架与模型交换文件，无动画。
- `build_kestrel.py`：Blender 3.6 后台生成脚本；`check_rig.py`：变形和 FBX 重导入检查。
- `Previews/`：正斜视、背部、头部与测试姿态渲染。
- 当前约 10.7 万三角形、84 根骨骼、12 个材质。模型源文件不是已优化的运行时资产。
- 已通过无缺失权重、权重和为 1、抬翼/转头/腿趾变形坐标有效、FBX 重导入后保留骨架和蒙皮检查。
- 尚未通过：写实外观验收、完整收翅叠层与穿插检查、游戏引擎材质验证、四段正式动画。
- 主要外观缺陷：羽毛排列及横斑重复感较强；翼根与头喙仍需造型细化，体羽需要更自然的过渡。

## 动画验收目标
- 起飞：身体预备、蹬离支撑、展翅下拍、收腿，并衔接飞行。
- 飞行：循环接缝连续，肩肘腕和飞羽共同运动。
- 悬停：独立循环，保持头部稳定，尾羽与双翼可微调。
- 降落：减速展尾、伸腿、接触缓冲、收翅；第一版暂按平地降落，树枝抓握之后细化。
- 与现有 Rigidbody 位移协调，默认动画原地播放，位移由游戏控制器负责。
